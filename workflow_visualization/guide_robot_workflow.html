Primary Flow

Prompt enters through the browser, app.py queues it, remote_agent_client.py translates MM prompts if needed, checks local Dijkstra routing, retrieves RAG context, then streams a Kaggle LLM response back as display and speech events.

Key Rule

Navigation facts come from navigation.py, not the LLM. The LLM only verbalizes route facts already produced by the local route system.

Local Hardware Timing

Audio playback, gTTS/Kokoro generation, and ESP32 mouth envelopes all happen on the laptop side so speech and lip-sync stay aligned.
