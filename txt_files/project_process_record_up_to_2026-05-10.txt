============================================================
1. Project Goal
============================================================

The project started as an attempt to build or fine-tune a fast Burmese TTS system that can run on the user's laptop.

Initial direction:
- Use Kokoro because it is fast and sounds good.
- Convert Burmese captions into phonemes first.
- Use the myG2P Burmese grapheme-to-phoneme dictionary.
- Prepare a Burmese female voice dataset.

The project later moved toward StyleTTS2 because Kokoro is based on StyleTTS2/ISTFTNet concepts and public Kokoro releases are mainly inference-oriented, not a clean official fine-tuning trainer.

Current direction:
- Train Burmese TTS using StyleTTS2.
- Use Burmese IPA phoneme text.
- Train a Burmese AuxiliaryASR aligner because the bundled StyleTTS2 ASR aligner is not compatible with the Burmese phoneme/token inventory.

Bug / issue:

- A check against train_list.txt and val_list.txt showed no missing characters.

- The highest tokenizer ID was 198.
- nn.Embedding(n_token, ...) accepts IDs 0 through n_token - 1.

Current intended value:

11. CUDA Device-Side Assert / ASR Token Mismatch
============================================================

After downloads and import fixes, training moved forward but crashed with:
- Assertion `srcIndex < srcSelectDimSize` failed
- RuntimeError: CUDA error: device-side assert triggered
- Crash location:
  - styletts2\Utils\ASR\models.py
  - decoder_inputs = self.embedding(_text_input)

Cause:
- The bundled StyleTTS2 pretrained ASR aligner had vocab size 178.
- Burmese tokenizer had IDs up to 198.
- Burmese text was being passed into the ASR aligner.
- Some text token IDs were larger than the ASR embedding table allowed.

Findings:
- Current Burmese data used 59 unique symbols.
- No unknown characters relative to the patched tokenizer.
- 21 symbols were above the pretrained ASR limit of 177.
- 2528 lines contained tokens outside the pretrained ASR vocabulary.

Important conclusion:
- The Burmese symbols are not junk.
- They are needed for the dataset.
- The bundled English/LibriTTS-era ASR aligner is incompatible with Burmese.

Decision:
- Do not delete Burmese IPA symbols just to fit the old ASR model.
- Train a Burmese ASR aligner instead.
